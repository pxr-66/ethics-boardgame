# 芯途抉择 · 工程伦理桌游

<img src="img/mascot.svg" width="96" align="right" alt="吉祥物小芯">

一款关于成长与选择的工程师桌游。玩家扮演半导体行业的新人工程师，沿 **芯片设计 → 晶圆制造 → 封装测试 → 终端应用** 产业链成长，在真实行业事件与没有标准答案的伦理困境中做出抉择。

走捷径来钱快，却会埋下「隐患」；守住底线要付出代价，却能赢得信任。你会成为怎样的工程师？

**在线游玩：** <https://pxr-66.github.io/ethics-boardgame/>

## 怎么玩

1. **掷骰子走格子**：停在哪一格就做哪一格的事——攻关项目、学习、抽行业事件或机遇
2. **攒技术做项目**：用技术攻关项目拿奖杯，奖杯是最值钱的得分
3. **伦理困境二选一**：每张困境卡都是「情境 — 选项 A / B — 后果」，没有标准答案。其他玩家会先猜你会怎么选
4. **小心隐患**：带捷径的选项当下收益更高，但会留下隐患，迟早会被翻出来
5. **算分**：游戏结束时总分最高的人成为 MVP 工程师，并看看自己是守护者、务实派还是冒险家

## 核心机制

- **行业信任**：所有人共用一条信任值。有人走捷径信任下降，降到 0 全员受罚；保持得好全员有红利。个人选择，集体后果
- **迟到的后果**：线上版是两轮后的「回响」，纸牌版是面朝下的隐患卡。出不出事、出多大的事常常靠运气，但「没出事」不等于「做对了」
- **猜一猜**：别人做选择前，大家先猜他会选什么。纸牌版里选完还要说一句理由，理由比答案更重要
- **三种工程思维**：每张困境卡标注系统思维、辩证思维或价值思维，并列出这个抉择牵动的利益相关方
- **4F 复盘**：结束后围绕 Feeling / Fact / Finding / Future 聊一聊，回顾自己的每一次抉择

## 和课程要求的对应

| 课程要求 | 游戏里的体现 |
| --- | --- |
| 角色卡 ≥ 4 张 | 6 个岗位角色：芯片设计、工艺、设备、封装测试、AI 算法、质量安全工程师，起始资源与专属技能各不相同 |
| 事件卡 ≥ 12 张 | 12 张行业事件（芯片断供、技术封锁、双碳政策、AI 算力爆发等，注明改编来源）+ 机遇卡；纸牌版另有 18 张隐患卡 |
| 伦理困境卡 ≥ 6 张 | 12 张，「情境—选项A/B—后果与资源增减」结构，无标准答案；纸牌版另附 3 张空白自创卡 |
| 棋盘 | 24 格，沿产业链四个环节推进 |
| 规则草案 | 线上版有交互式教程；纸牌版有规则书，格子上直接印出效果，一局 ≤ 40 分钟 |

## 技术说明

纯静态网页（HTML / CSS / JavaScript + Three.js），不需要自己的服务器。联机和评论都通过公共 MQTT 服务器（broker.emqx.io、HiveMQ、Mosquitto）转发和保存，仅适合课堂使用，聊天和评论里不要发送个人隐私。

- 修改 `js/board3d.js` 后重新打包 3D 棋盘：`bash tools/build-3d.sh`
- 修改卡牌文字后重新生成纸牌版 PDF：`node tools/paper/build.mjs`（需要本机装有 Chrome 或 Edge）

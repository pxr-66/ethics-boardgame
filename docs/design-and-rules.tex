\begin{note}{pri}
\small\textbf{一句话核心循环：}玩家通过\textbf{掷骰前进}获取\textbf{技术与资金}，用以\textbf{攻关项目、成长为资深工程师}，同时应对\textbf{真实行业事件与伦理困境}，最终以\textbf{总分最高}成为 MVP。我们想让玩家亲身体会课上那句话：\kai{当工程思维走到「价值」与「边界」，工程伦理就已经在场。}
\end{note}

\begin{multicols}{2}
\begin{card}[\faIcon{balance-scale}\enspace 1. 两难卡：没有标准答案]{rose}
\small 课程要求困境卡「真的两难」。我们 12 张困境卡里，\textbf{每个选项都有代价}：走捷径短期收益高（\res{mint}{+3 资金}），但会留下\res{bad}{隐患}；坚守底线要付出成本（\res{bad}{−1 资金}），换来声誉。题材全部来自第 2 周地图上标注的「双刃剑」点位：赶工期 vs 安全测试、数据授权、供应商利益输送、成果署名、双碳指标 vs 成本……

\textbf{取舍理由比答案更重要}，所以每张卡结算后都有一道「想一想」，并可一键打开聊天说理由。
\end{card}

\begin{card}[\faIcon{layer-group}\enspace 2. 工程思维透镜：把阅读材料放进卡里]{sky}
\small 每张困境卡都标注它对应《工程思维的特点》中的哪一种思维与维度，并列出\textbf{牵动谁}（利益相关方）：
\begin{itemize}
\item \lens{sky}{系统思维} 技术之外还牵动什么？如「废液处理」牵动社区与生态
\item \lens{lav}{辩证思维} 哪里是双刃剑？如「发现隐藏缺陷」中公众安全 vs 组织利益
\item \lens{sun}{价值思维} 价值如何流动？如「供应商的心意」触碰运营制度
\end{itemize}
玩家在做选择时，自然就在用课上的框架分析问题。
\end{card}

\begin{card}[\faIcon{heart}\enspace 3. 行业信任：个人选择，集体后果]{pri}
\small 所有玩家\textbf{共享}一条「行业信任」。任何人走捷径，信任 −2；坚守 +1。降到 0 会爆发\textbf{信任危机}，所有人一起受罚；结束时信任够高，所有人都有口碑红利。

这对应现实：一家企业的造假丑闻，会让公众怀疑整个行业。\kai{一个人的捷径，代价却由所有人承担}，这正是工程伦理中个人利益与公共利益的张力。玩家也因此会互相劝阻、讨论，形成真实的伦理对话。
\end{card}

\begin{card}[\faIcon{redo}\enspace 4. 选择的回响：后果会迟到]{lav}
\small 现实中伦理决策的后果往往\textbf{延迟出现}。困境卡里的选择会在\textbf{两轮后}以「回响卡」回来：坚守测试的芯片零故障、客户追加订单；先发货的芯片被要求返修。

回响是\textbf{概率性}的：走捷径不一定被发现，坚守也不一定立刻被看见。这避免了「好人一定有好报」的说教，更贴近真实。
\end{card}

\begin{card}[\faIcon{newspaper}\enspace 5. 让学习回归真实]{sun}
\small 12 张行业事件卡全部\textbf{改编自真实事件并注明出处}：芯片出口管制、光刻机限制、「双碳」目标、2021 年汽车缺芯潮、AI 算力需求爆发、国家集成电路产业投资基金、RISC-V 推广……

6 个角色来自第 2 周岗位画像：芯片设计、工艺、设备、封装测试、AI 算法、质量安全工程师，起始资源和专属技能各不相同。
\end{card}

\begin{card}[\faIcon{comments}\enspace 6. 复盘：游戏结束才是讨论的开始]{mint}
\small 结算页不只显示 MVP，还会：
\begin{itemize}
\item 根据选择给出\textbf{工程师类型}：守护者 / 务实派 / 冒险家，并按三种思维统计「守住底线」的次数
\item 展示\textbf{同一张卡大家各选了什么}，方便请两边各说理由
\item 回顾自己的每个抉择，并给出 \textbf{4F 复盘}题（感受 / 事实 / 发现 / 未来）
\end{itemize}
\end{card}

\begin{note}{sky}

\begin{card}[\faIcon{balance-scale}\enspace 伦理困境（重点）]{rose}
\small
\begin{itemize}
\item 两个选项都有代价。带\textbf{\color{bad}隐患}的选项短期收益高，但每个隐患结算时 \textbf{−3 分}，还可能在安全审计或「质量暴雷」事件中被罚。
\item \textbf{猜一猜}：别人遇到困境时，你可以猜 TA 会选什么，猜中 +1 资金。
\item \textbf{回响}：你的选择两轮后可能回来找你，带来奖励或惩罚。
\end{itemize}
\end{card}

\begin{card}[\faIcon{heart}\enspace 行业信任（大家共享）]{pri}
\small
\begin{itemize}
\item 从 6 开始。任何人在困境里\textbf{走捷径 −2}，有捷径却\textbf{坚守 +1}。
\item 降到 \textbf{0}：信任危机，所有人 −2 资金，有隐患的人再 −2 声誉。
\item 结束时 \textbf{$\ge$ 6}：所有人获得口碑红利 +3 资金。
\end{itemize}
\end{card}

\begin{note}{mint}
\small\textbf{\faIcon{flag-checkered}\enspace 游戏结束：}标准局 3--4 人 8 轮、5--6 人 6 轮；快速局 5 轮。结算页显示 MVP、排名、特别奖、你是哪种工程师，以及大家在每张困境卡上的选择。\textbf{别急着关掉}：挑一张大家选法不同的卡，请两边说说理由，这才是这个游戏最有意思的部分。
\end{note}
